## 3. なぜGitHubと公開版に差がある？
最初はGitHubから直接デプロイしようとしましたが、VercelがGitHub APIのアクセス制限（429）に遭遇しました。

そこでVercelにファイルを直接送る方法で公開しました。この際、公開版の画像URLだけを **GitHubの公開画像URLへ差し替える** 一時対応を入れました。
一方、GitHubの `app.py` では `/images/...` のURLを返す設計です。

**つまり、現在の公開版とGitHubのソースは画像URLの取り扱いだけ完全一致していません。** GitHubとの自動連携・差分解消は今後の作業です。GitHubのREADMEや教材を更新しても、直ちに本番アプリの画面・処理が変わるわけではありません。

## 4. 実際に起きた障害と修正
初期のデプロイではPythonのimport時に：
~~~text
RuntimeError: Directory '/var/task/public' does not exist
~~~
というエラーが出ました。原因はVercelが配信する静的ファイルと、Python実行環境内のファイル配置が異なること。

修正：Vercelでは `public/` をPythonにマウントせず、ローカル実行だけで `StaticFiles` を使用する条件分岐を `app.py` に追加しました。修正版で `/api/health` などの応答を確認しました。
